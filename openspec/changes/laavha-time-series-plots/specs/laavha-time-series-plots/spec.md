## ADDED Requirements

### Requirement: Time-Series Plot Input

The plotting tool SHALL accept time-series CSV files generated by
`laavha_inference.py`.

#### Scenario: Single time-series file

- **WHEN** the user provides one time-series CSV
- **THEN** the plotting tool SHALL load it and generate time-series plots

### Requirement: Score And Metric Plots

The plotting tool SHALL produce plots for scores and signal metrics over time.

#### Scenario: Score plot

- **WHEN** the time-series CSV contains score columns
- **THEN** the plotting tool SHALL generate a score-over-time plot for 5G, LTE,
  and WiFi

#### Scenario: SINR plot

- **WHEN** the time-series CSV contains SINR columns
- **THEN** the plotting tool SHALL generate a SINR-over-time plot for 5G, LTE,
  and WiFi

### Requirement: Handover Timeline

The plotting tool SHALL visualize selected network changes and handover events.

#### Scenario: Network timeline plot

- **WHEN** the time-series CSV contains current network, target network, and
  handover columns
- **THEN** the plotting tool SHALL generate a network timeline plot and mark
  handover events
