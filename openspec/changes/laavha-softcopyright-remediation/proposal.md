# LAAVHA软著材料整改计划

## 背景

当前LAAVHA项目已经具备训练、在线推理、NS-3仿真交互、批量实验和结果绘图等学术成果对应的软件代码，但现有软著材料与模板之间仍存在版式不统一、摘要和设计说明书偏论文/AI表达、源程序前后30页图片化、设计书缺少真实操作界面等问题。

## 目标

将现有软著材料整理为可审核、可追溯、与代码一致的登记材料包。所有技术表述以当前项目实际代码和已验证运行结果为依据，申请表中的法律登记信息保留明确的待确认项。

## 范围

本次变更覆盖：

1. 登记信息和源程序范围确认。
2. 内容摘要重写及字数校验。
3. 设计说明书按模板重排和技术内容重写。
4. 真实软件操作界面或命令行运行界面补充。
5. 完整源程序及前30页后30页文本版本重建。
6. DOCX/PDF生成、页数、可检索性和跨文档一致性验收。

## 非目标

- 不修改LAAVHA运行算法、NS-3仿真逻辑、实验数据或论文内容。
- 不把模板中的VRPTW、ECSN、DPN、三维A*、Web地图或数字孪生功能写入LAAVHA材料。
- 不声称真实NR/5G-LENA物理层测量、协议级WiFi/LTE附着切换或生产网络控制能力。
- 不猜测著作权人、证件、分类号、开发日期和发表状态等法律信息。

## 验收结果

第一阶段完成后必须形成：登记信息基线、源程序清单、依赖清单、排除项记录、待确认事项清单，以及可执行的后续阶段任务。
