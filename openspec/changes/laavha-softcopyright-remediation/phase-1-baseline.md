## 4. 运行依赖和边界

- Python 3.10+、PyTorch、NumPy、Pandas、Matplotlib。
- NS-3.45、ns3-ai、pybind11和C++构建工具。
- `LAAVHA算法模型.pth`模型权重。
- 训练脚本读取`LAAVHA_Training_Dataset.csv`，仓库另有`训练数据集.csv`，文件名映射需在后续运行前明确。
- 5G候选网络采用NS-3中的代理链路/传播模型口径，不是NR/5G-LENA物理层实现。
- 输出为决策层网络编号和评分，不是协议级WiFi/LTE attach/detach切换。
