# 软著材料校验清单

## 内容与字段

- [ ] 软件名称、简称、版本号在所有文档一致。
- [ ] 著作权人、开发日期、分类号和发表状态已由用户确认。
- [ ] 开发目的不超过50字。
- [ ] 面向行业/领域不超过50字。
- [ ] 主要功能在500—1300字之间。
- [ ] 技术特点不超过100字。

## 技术一致性

- [ ] 指标顺序为SINR、RSRP、Delay、Throughput、PLR。
- [ ] 网络编号为0=5G、1=LTE、2=WiFi。
- [ ] 设计说明书中的函数名、文件名和消息字段均可在源程序中定位。
- [ ] LAAVHA、ALERA、TOPSIS、双重滞后和风险感知增强的描述与代码一致。
- [ ] 未将应急双网规划模板中的VRPTW、ECSN、3D A*或Web系统写入当前软件功能。
- [ ] 未将代理链路指标写成真实物理层测量或协议级切换。

## 文件与渲染

- [ ] 完整源程序清单已生成并记录文件行数和哈希。
- [ ] 完整源程序不超过60页；若超过则生成首30页加末30页版本。
- [ ] 设计说明书包含架构图、工作流程图、模块/函数/接口、算法、运行设计和测试边界。
- [ ] DOCX经LibreOffice渲染后无严重分页、空白页或乱码。
- [ ] 生成PDF的页数、渲染器和日期已记录。
