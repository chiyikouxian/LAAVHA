# English Terminology Glossary

| Source concept | Canonical English form | Use |
| --- | --- | --- |
| LAAVHA | Long Short-Term Memory-Attention based Adaptive Vertical Handover Algorithm (LAAVHA) | Define once, then use LAAVHA. |
| ALERA | Attention-LSTM Enhanced Risk-aware Vertical Handoff Algorithm (ALERA) | Define once, then use ALERA. |
| ADH | Adaptive Dynamic Hysteresis (ADH) | Use for the adaptive threshold and confirmation-window mechanism. |
| RS-TOPSIS | Risk-Sensitive TOPSIS (RS-TOPSIS) | Use for robust-score candidate ranking. |
| TOPSIS | Technique for Order Preference by Similarity to Ideal Solution (TOPSIS) | Use the acronym after its first definition. |
| vertical handover | vertical handover | Use `handover` for the generic network-transition process. |
| vertical handoff | vertical handoff | Retain in the canonical ALERA expansion. |
| dual hysteresis | dual hysteresis | Use for the score-gap threshold plus consecutive-confirmation window. |
| candidate network | candidate network | Use for 5G, LTE, and WiFi alternatives. |
| serving network | serving network | Use for the currently connected network. |
| closeness | closeness score | Use for $C_i$; use robust closeness score for $C_i^{\mathrm{robust}}$. |
| SINR | signal-to-interference-plus-noise ratio (SINR) | Keep the standard acronym in equations and tables. |
| RSRP | reference signal received power (RSRP) | Keep the standard acronym in equations and tables. |
| PLR | packet loss ratio (PLR) | Keep the standard acronym in equations and tables. |
| throughput | throughput | A benefit criterion. |
| delay | end-to-end delay | A cost criterion. |
| ping-pong handover | ping-pong handover | Use for rapid back-and-forth transitions. |
| necessary handover | necessary handover | Use for a correct transition during sustained degradation. |
| false handover | false handover | Use for a transition induced by transient fluctuations. |

Capitalization convention: capitalize only proper names and defined method names. Use sentence case for headings, captions, table entries, and generic technical concepts. Keep variable names, equation labels, figure/table/algorithm labels, asset paths, and manual citation arguments unchanged.
