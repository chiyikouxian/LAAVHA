# 问题3：决策层切换边界澄清 - 分析报告

**日期**：2026-10-13  
**优先级**：🔴 高（技术准确性问题）  
**问题类型**：语义混淆 - 决策层网络选择 vs 完整协议栈切换

---

## 📋 问题描述

### 核心问题
论文第15页（原始稿）明确指出：
> "A handover event denotes a change in the network identifier selected by LAAVHA, rather than an actual Wi-Fi disassociation, LTE detachment, or 5G new-radio protocol-stack handover."

**关键事实**：
- ✅ **实际仿真内容**：决策层网络选择（选择哪个网络标识符）
- ✅ **5G使用代理链路**：通过位置传播模型计算SINR/RSRP，而非真实5G协议栈
- ✅ **切换事件定义**：算法选定的网络标识发生变化
- ❌ **不包含**：Wi-Fi重关联、LTE detachment、5G NR协议栈切换

### 当前论文的问题
摘要和结论中使用了模糊表述，可能让读者误认为：
1. 仿真验证了完整的真实异构网络切换过程
2. "handover count reduction"意味着降低了通信中断时延
3. 改善了协议切换开销和链路重建延迟

### 真实研究边界
**我们验证的是**：
- ✅ 智能网络选择决策的稳定性
- ✅ 什么时候切换（when to switch）
- ✅ 切换到哪个网络（which network to switch to）
- ✅ 如何避免反复切换（ping-pong suppression）

**我们未验证的是**：
- ❌ Wi-Fi重关联过程（authentication, association）
- ❌ LTE detachment和attach过程
- ❌ 5G NR RRC连接重配置
- ❌ IP地址迁移和数据转发
- ❌ 真实通信中断时延
- ❌ 完整协议切换开销

## 🔍 当前论文中的问题位置

### 位置1：摘要（第82-83行）
**当前表述**：
```
Simulation results demonstrate reduced unnecessary handovers, improved decision 
efficiency, sustained service continuity, and greater robustness to abrupt 
channel variations in heterogeneous wireless networks.
```

**问题**：
- "sustained service continuity" 暗示改善了真实通信连续性
- 未明确说明这是决策层仿真

**建议修改**：
```
Simulation results at the decision level demonstrate reduced unnecessary network 
selection changes, improved decision efficiency, and greater robustness to abrupt 
channel variations in heterogeneous wireless networks.
```

---

### 位置2：摘要最后一句（第82-83行）
**当前表述**：
```
In 50 random scenarios, the handover count is only 0.24, achieving 84.8%-99.1% 
reduction compared to eight baseline algorithms.
```

**问题**：
- "handover count" 可能被误解为真实协议切换次数

**建议修改**：
```
In 50 random scenarios, the network selection change count is only 0.24, achieving 
84.8%-99.1% reduction compared to eight baseline algorithms.
```

或者：
```
In 50 random scenarios, the decision-level handover count is only 0.24, achieving 
84.8%-99.1% reduction compared to eight baseline algorithms.
```

---

### 位置3：第411行（仿真设置）
**当前表述**（已存在，但位置靠后）：
```
A handover event denotes a change in the network identifier selected by LAAVHA, 
rather than an actual Wi-Fi disassociation, LTE detachment, or 5G new-radio 
protocol-stack handover.
```

**问题**：
- ✅ 这句话本身是正确的
- ⚠️ 但它出现在仿真设置章节，而非摘要或引言
- ⚠️ 读者可能在看到摘要和结论后已经形成错误理解

**建议**：
- 保留这句话
- 在摘要、引言、结论中增加类似说明

---

### 位置4：结论（第495行）
**当前表述**：
```
ALERA completes all necessary handovers under sustained degradation and produces 
zero false handovers under transient variation, demonstrating reliable and stable 
data transmission for UAV aerial missions in heterogeneous wireless networks.
```

**问题**：
- "completes all necessary handovers" 暗示完成了真实切换过程
- "reliable and stable data transmission" 暗示改善了真实数据传输质量

**建议修改**：
```
At the decision level, ALERA completes all necessary network selection decisions 
under sustained degradation and produces zero false selections under transient 
variation, demonstrating stable network selection decision-making for UAV aerial 
missions in heterogeneous wireless networks.
```

或者更明确：
```
ALERA's decision-level evaluation shows that it completes all necessary network 
selection changes under sustained degradation and produces zero false changes 
under transient variation. This validates the stability of the proposed network 
selection strategy for UAV aerial missions, though the complete protocol-stack 
handover process (including authentication, link reestablishment, and data 
forwarding) remains outside the current simulation scope.
```
