## 修改策略

### 替换规则

| 原术语 | 替换为 | 适用场景 |
|--------|--------|---------|
| **UAV remote-sensing missions** | UAV aerial missions in heterogeneous wireless networks | 通用 |
| **remote-sensing cruise** | aerial missions / cruise missions | 通用 |
| **remote-sensing performance** | aerial mission performance / mission performance | 性能描述 |
| **remote-sensing data continuity** | service continuity / data transmission continuity | 服务质量 |
| **remote-sensing support** | network support / service quality | 网络能力 |
| **UAV remote sensing** | UAV heterogeneous wireless networks | 领域描述 |
| **remote-sensing scenarios** | aerial mission scenarios / heterogeneous network scenarios | 场景描述 |

### 修改原则

1. ✅ **保持技术中性**：避免限定特定应用（遥感/车联网/ITS）
2. ✅ **突出核心主题**：强调"heterogeneous wireless networks"
3. ✅ **保持简洁**：不过度堆砌长短语
4. ✅ **上下文一致**：确保替换后的术语与段落其他内容协调
